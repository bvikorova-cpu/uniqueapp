# Eleven 15-second Kids videos

## Goal
Create eleven separate English vertical promotional videos for Kids Channel, Coloring Pages, Kids Puzzles, Homework Helper, Story Creator, Science Lab, Drawing Buddy, Reading Companion, Fairytale Book Generator, Kids Collectibles, and Career Counselor.

## Deliverables
- Generate one distinct, bright, child-friendly original image for each topic.
- Keep every image free of third-party characters, brands, text, logos, and watermarks.
- Add concise English copy and comfortably paced English narration to each video.
- Use the existing Unique logo, visible `uniqueapp.fun` URL, music, intro, feature scene, and closing scene.
- Set every composition to approximately 15 seconds in 1080×1920, 30 FPS, MP4 with sound.
- Render all eleven videos into the downloadable documents area.

## Technical details
- Extend the existing category teaser data and duration map with eleven new IDs.
- Extend output filenames in the existing render script.
- Generate narration audio sized for the 15-second runtime.
- Verify all outputs with media metadata and inspect representative frames for readability and safe placement.
